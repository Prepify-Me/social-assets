# PrepifyMe social assets

Public host for the images/videos of PrepifyMe's scheduled social posts (TikTok,
Facebook, LinkedIn, YouTube Shorts). Files are pushed here automatically by the
`content-studio` weekly pipeline so Metricool can download them by URL.

Nothing here is secret: it is exactly what gets published on the public accounts.
Layout: `weeks/<YYYY-MM-DD>/` = one week's batch (`plan.json` + media files).
